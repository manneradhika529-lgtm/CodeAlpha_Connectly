\# Connectly – Social Media Web Application



Connectly is a social media web application developed using Django. It allows users to create accounts, connect with other users, create posts, like posts, send friend requests, and receive notifications.



\## Features



\- User Registration and Login

\- User Logout

\- User Profiles

\- Create Posts

\- View Posts

\- Like Posts

\- Delete Posts

\- Friend Requests

\- People You May Know

\- Notifications

\- Profile Statistics

\- Responsive User Interface



\## Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- JavaScript

\- SQLite

\- Git \& GitHub
